# 常规代理季卡、年卡入口

按用户确认：月卡现价 299 积分；季卡为三个月原价的 95%，四舍五入至 852 积分 / 90 天；年卡为十二个月原价的 85%，四舍五入至 3050 积分 / 365 天。使用既有商城积分购买，无自动续费。

用户另加独立 120 天套餐，保留 90 天季卡。120 天套餐按四个月月价的 95% 准备，为 1136 整数积分，不替换季卡。

后端在私有 studio-billing PR #1。订单保留 proxy_3m / proxy_4m / proxy_1y，实际代理权益沿用客户端识别的 proxy_1m 服务码，purchase_product 表示购买周期。账户页据此显示季卡、120天套餐和年卡。

此目录只部署 deployment-baseline.json 列出的五个文件。fixtures 是从公开页面保存的演示依赖，仅供 GitHub Actions 的离线浏览器用例；不发布。测试以虚拟域名拦截全部 API，验证真实前端的报价、所选 SKU、权益名称及 390/1280px 布局；不创建真实付款或修改生产余额。

发布前核对每个线上原文件 SHA-256，变动则停止并合并。后端及静态文件先在站点目录外备份，再原子替换。网站成品仅在本工作流通过后保留，不代表五平台浏览器应用已完成商业发行。
