05 / 排查指南

遇到卡顿时

  1. 先执行「当前连接质量」测试，看官网访问是否稳定。
  2. 在代理客户端中选择可连通、延迟较低的线路，尽量避免显示异常的 TCP 节点。
  3. 若 UDP 线路未验证，请使用支持 Hysteria2/TUIC 的客户端自行检测。
  4. 如果已经订阅但节点仍不可用，请检查 我的订阅 是否有效。

结果代表什么？

  1. TCP 可达：只能证明服务器可建立 TCP 连接，不代表账号认证或代理完整可用。
  2. 连接超时：网关当前无法连上，不代表所有运营商都无法连上。
  3. UDP 待验证：不是故障判定。
  4. 浏览器 HTTP 延迟：网站访问质量，不是指定代理节点的真实出口 RTT。
