客户端导入步骤

Clash Meta / Clash Verge / Mihomo：复制「Clash」链接，在客户端「配置文件 → 从 URL 导入」粘贴即可，支持自动更新。
Karing（iOS） / v2rayN / Shadowrocket / Nekoray：复制「v2ray」明文节点链接直接导入，或用「base64」作为订阅 URL 导入。
菲律宾等地区手动选择：更新 Clash 专用订阅，在「代理 / PROXY」中选择「🇵🇭 菲律宾 · 手动选择」；也可选择「🇦🇺 澳大利亚」「🇭🇰 香港」「🇰🇷 韩国」的手动分组。地区手动组提供近期 HTTPS 检查通过的线路，包括可能较慢的备用节点。默认自动组仍优先使用测速达标线路；部分 TCP 故障备用线路可能低速。若分组消失，可能是该地区线路未通过近期健康检查。
韩国游戏固定出口：更新 Clash 专用订阅后，在「代理 / PROXY」里选择「🇰🇷 韩国游戏 · 固定韩国出口（共享）」，通过合格的韩国节点连接，不会在游戏中自动跳到香港或澳大利亚。游戏客户端请开启 Clash Verge Rev 的 TUN 模式；如游戏未进入代理，可临时切到全局模式再测试。当前韩国线路为共享数据中心出口，并非独享家宽。
无需手动选节点：在 Clash Verge Rev / Mihomo 中导入或更新 Clash 专用订阅并使用「规则模式」。默认由「♻️ 自动选择」处理普通网站，按域名自动接管 YouTube 和 ChatGPT，无需切换代理模式或反复测速。
YouTube 自动容错：网页与视频 CDN 都走「📺 YouTube · 自动容错」，定时检测 YouTube 官方 204 端点；首选线路连不上时自动启用备用线路。此检测不能证明 1080p 视频不会缓冲。
ChatGPT 自动容错：登录、会话和 OpenAI 相关域名统一使用「🤖 ChatGPT · 自动容错」。通过未授权 API 的 401 响应验证线路可达；自动保持同一出口，仅在检测失败时故障切换，减少登录中途换 IP。401 不等于已验证登录或对话成功。
异常才需要人工操作：正常使用不用调整；如果校园网等网络限制 UDP，客户端会自动尝试备用节点。极少数自动探测与真实网站体验不一致时，可临时手动切换。查看检测报告。
普通节点类型：普通节点完整目录保留全部收录协议和地区；已验证订阅单独列出通过检测的节点。两种入口均在本页提供。其他导出格式 sing-box / Surge 的完整配置验收仍在进行。
