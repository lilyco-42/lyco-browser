## 具体界面方向

官方截图可见左侧功能导航、顶部工作区、中央环境表格；创建页集中编辑并提供右侧参数预览。LYCO 参考其信息组织，使用自己的文字、样式和组件。

| 区域 | LYCO 拟采用的组织方式 |
| --- | --- |
| 左侧导航 | 环境、代理、账户与订阅；团队等能力完成并验收后再提供入口 |
| 环境顶部 | 搜索、分组筛选、创建环境；批量操作明确显示选中数量 |
| 环境表格 | 名称、分组/标签、绑定线路、运行状态、最近实际网络检测、启动/停止、更多操作；无检测记录显示“未检测” |
| 创建与编辑 | 基础信息和线路优先；高级指纹按需展开。区分保存、创建与启动，明确当前账号与目标环境 |
| 线路变更 | 展示当前与目标线路，提示先停止本环境；操作失败保留原绑定，其他环境的连接不能改变 |
| 订阅状态 | 展示已购套餐、到期时间、刷新状态及官网续费入口；月卡、90 天季卡、120 天套餐、年卡均沿用现有权益规则 |
