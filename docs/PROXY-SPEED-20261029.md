# 2026-10-29 代理速度 P0

用户报告连接代理后网页和下载变慢；后续明确只通过 SSH 操作服务器。本次使用已有主站、韩国共享节点和澳洲节点，服务器排查与部署均经 SSH，未新增付费资源。全部产品验证在真实 GitHub Actions 执行。

## 已部署的修复

旧会员中转仍连接失效上游，出现持续 SYN 重传；实际两个 HTTPS 页面及双下载均超时。先恢复可用出口，并修正 Google 域名解析到中国大陆地址的问题。节点证书补齐 SAN，公钥保持不变；网关信任从已有可信 SSH 获得的确切公开证书，没有关闭 TLS 校验。原证书保留私有备份。

较长样本确认韩国出口持续带宽偏低，不能用早期 1.5 MB 的短时峰值宣布问题解决。临时 BBR 对比没有改善，已恢复原 CUBIC，未写入持久设置。澳洲现有出口的实际 GitHub 文件明显更快，因此验证并部署主站到澳洲的 SSH TCP 中转，作为会员网页和下载流量的新路径。

SSH 使用独立服务器身份，私钥只保存在主站；澳洲端将该身份限制为指定主站来源、禁止交互命令和终端、仅用于转发。主站 SOCKS 入口仅监听回环，由 systemd 维护重连。账号、订阅 URL、节点名称和原凭据保留；原 UDP 路由保留。本次提升范围为 TCP 网页和文件传输，不宣称全部 UDP/IPv6 或客户端所在地网络均已验证。

默认 Clash 自动选择和稳定优先组现优先使用已验证的会员中转。只有当前核心路由与验收记录一致才启用该偏好；原备用节点和客户端 fallback 健康检查保留。站点专用组另要求相应站点的实际状态码，不能用通用测速证明视频播放或账户登录。刷新订阅后选择「自动选择」即可使用新顺序，原手动国家线路继续保留。

## 部署与回滚

先按原始摘要核对运行配置，再完整检查待部署配置；原子替换并保留私有备份。SSH 路由部署失败恢复本次网络字段并保留最新入站账号。默认选线部署只修改政策模块及四处调用，保留产品条款和数据库；月卡/季卡/120天/年卡仍为 299/852/1136/3050 积分及 30/90/120/365 天。

首次默认选线验收 [40867190305](https://github.com/lilyco-42/lyco-browser/actions/runs/40867190305) 因其他商品没有 duration_days 而失败、回滚。修正为只核对四档代理商品。SSH 调度器也修正为仅重试明确的认证前失败，远端业务失败或连接中断立即停止；四项控制流回归防止重复执行部署。

CI 临时身份在 Actions 内生成，只传递公开密钥，服务器限制为固定 root-owned 命令并设短期有效期；实际执行脚本、策略模块与生成器验收脚本的 SHA-256 必须等于 checkout。原始结果 ZIP 完整大小、SHA-256 和 CRC 均保存核验。验证结束撤销临时授权并移除测试 helper，生产 SSH 身份与运行服务独立保留。

私有 Billing 仓库的首次托管任务因账户账单限制未启动；实际验证由公开客户端仓库的 Actions 经受限 SSH 完成。两仓库 PR 保持草稿；没有借此发布五平台商业成品或替换客户端默认安装包。
